# StockFlow API

API REST para gerenciamento de produtos, fornecedores, categorias e movimentações de estoque.

Projeto desenvolvido como desafio técnico da trilha Back-End do Prosel 2026.2 da EcompJr.

## Tecnologias

- Python
- FastAPI
- PostgreSQL
